# Paymentus

This profile was removed at the request of Paymentus.

On 2026-09-17, Vitali Smirnov, on behalf of Paymentus, asked API Evangelist to take
down this profile. We honor removal requests. The API index that was here — the
`apis.yml` descriptor and every derived artifact (OpenAPI, security, scopes, MCP,
packages, llms, authentication, and the rest) — has been deleted, and Paymentus has
been added to our do-not-list registry so it is not re-published by any future harvest.

What remains, on apis.io only, is a minimal, **unrated** record: the company name, a
neutral factual description, and a link to Paymentus's own website
(<https://www.paymentus.com/>). No score is published against Paymentus.

**Paymentus:** Paymentus (NYSE: PAY) is an Addison, Texas-based cloud billing and
payment technology company, founded in 2004, that operates one of the largest
electronic bill presentment and payment (EBPP) networks in North America.
